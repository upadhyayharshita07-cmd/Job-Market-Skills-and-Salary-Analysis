# Technologies Used in Job Market and Skills and Salary Analysis

1. Python: Used for data processing and analysis.

2. Pandas: Used to clean and analyze job market data.

3. Flask: Used to create the backend of the web application.

4. Flask-CORS: Used for communication between frontend and backend.

5. HTML: Used to create the structure of the website.

6. CSS: Used to design and style the website.

7. JavaScript: Used to make the website interactive.
