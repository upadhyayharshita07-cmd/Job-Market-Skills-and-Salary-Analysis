# Folder Structure

```
Job-Market-Skills-and-Salary-Analysis/
├── app.py                              # Main Flask app: loads the CSV with Pandas and serves the API endpoints
├── naukri_data_science_jobs_india.csv  # Dataset of data science job postings from Naukri
├── requirements.txt                    # List of Python packages needed to run the project
├── README.md                           # Project title and short description
├── docs/                               # Documentation files written by the team
│   └── folder_structure.md             # This file: explains the project folder layout
├── static/                             # Files the browser loads directly (CSS and JavaScript)
│   ├── css/
│   │   └── style.css                   # Styling (layout, colours, fonts) for the web page
│   └── js/
│       └── script.js                   # Fetches data from the API and shows it on the page
├── templates/                          # HTML pages that Flask shows in the browser
│   └── index.html                      # Main page: overview, skills, roles, search and salary sections
└── reference and content/              # Reference material and supporting content for the project
```
